# 🔔 UniteAlarm

UniteAlarm adalah aplikasi alarm & pengingat berbasis **Python** yang dirancang untuk penggunaan desktop Windows.  
Aplikasi ini mendukung **jadwal alarm**, **tray system**, **mode portable**, dan **build installer**.

---

## ✨ Fitur Utama
- ⏰ Alarm berbasis jadwal (JSON)
- 🖥️ Tray icon (jalan di background)
- 🔊 Dukungan suara / audio alarm
- 📅 Pengaturan hari libur
- 🧳 Mode portable
- 📦 Build executable & installer (Inno Setup)
- 🎨 Icon kustom
