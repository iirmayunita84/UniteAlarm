UNITEALARM
==========

UniteAlarm adalah aplikasi alarm harian ringan untuk Windows.
Dirancang untuk berjalan stabil di background tanpa membebani CPU.

Fitur Utama:
- Alarm otomatis berdasarkan jam
- Suara alarm custom (WAV)
- System Tray (tetap aktif saat jendela ditutup)
- Mode Silent (tanpa suara)
- Mode Libur
- Hemat CPU & RAM

Cara Pakai Singkat:
1. Jalankan UniteAlarm
2. Tambahkan jadwal alarm
3. Klik "Jalankan Alarm"
4. Tutup jendela → alarm tetap aktif di tray

Format Audio:
- WAV
- PCM 16-bit
- 44100 Hz

Folder Penting:
- voices/  → tempat file suara
- AppData/UniteAlarm → data jadwal

UniteAlarm cocok untuk:
- Pengingat aktivitas harian
- Alarm kerja / ibadah
- PC yang menyala lama
