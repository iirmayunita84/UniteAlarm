💖 UniteAlarm

Pengingat Jadwal Harian dengan Suara

UniteAlarm adalah aplikasi alarm jadwal harian yang membantu mengingatkan aktivitas dengan suara otomatis, cocok untuk kerja rumahan, usaha, dan rutinitas harian.

🚀 Cara Instal (Disarankan)

Jalankan file:
UniteAlarm_Setup.exe

Klik Next → Install

Setelah selesai, klik Finish

👉 UniteAlarm akan terpasang di komputer dan siap digunakan.

▶️ Cara Menjalankan

Klik UniteAlarm Panel di Desktop
atau

Start Menu → UniteAlarm Panel

🔔 Cara Menggunakan UniteAlarm
1️⃣ Mengatur Jadwal

Isi:

Jam (HH:MM) → contoh 07:00

File suara → pilih dari daftar

Pesan → teks pengingat

Klik Tambah

📌 Setiap edit akan otomatis tersimpan, tidak perlu tombol Save.

2️⃣ Edit Cepat

Klik 2x (double click) pada tabel jadwal

Ubah isi kolom

Tekan Enter → otomatis tersimpan

3️⃣ Preview Suara

Pilih file suara

Klik Preview

Jika bunyi → berarti format sudah benar ✅

4️⃣ Mode Libur 💤

Klik tombol Libur

Alarm tidak akan berbunyi

Klik lagi untuk mengaktifkan kembali

5️⃣ Jalankan Alarm

Klik Jalankan Alarm

Aplikasi boleh diminimalkan

UniteAlarm tetap aktif di background

🔊 Format Suara yang Didukung

UniteAlarm hanya mendukung format berikut:

WAV

PCM

16-bit

44.100 Hz

❌ MP3 tidak langsung didukung
💡 Gunakan converter (misalnya Convertio / CloudConvert) dengan pengaturan PCM 16-bit.

📁 Lokasi Data

Data disimpan otomatis di:

C:\Users\<NamaUser>\AppData\Roaming\UniteAlarm\


Isi:

jadwal.json → jadwal alarm

libur.txt → status libur

⚠️ Jangan hapus file ini kecuali ingin reset data.

🛠️ Troubleshooting
❓ Alarm tidak bunyi

Pastikan:

Alarm dalam status AKTIF

Mode Libur OFF

File suara format WAV PCM

❓ Preview tidak bunyi

File suara kemungkinan format tidak didukung

Convert ulang ke WAV PCM 16-bit

❌ Cara Uninstall

Control Panel → Programs

Pilih UniteAlarm

Klik Uninstall

Data akan ikut terhapus otomatis.

❤️ Penutup

UniteAlarm dibuat untuk membantu aktivitas harian lebih teratur dan tenang.
Kalau alarm bunyi tepat waktu, berarti dia lagi kerja 😄
