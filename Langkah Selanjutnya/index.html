✨ Tentang UniteAlarm

UniteAlarm adalah aplikasi alarm desktop Windows yang dibuat untuk rutinitas harian: kerja, belajar, menjahit, atau pengingat pribadi. Fokus pada stabilitas, hemat CPU, dan bebas ribet.

🚀 Fitur Unggulan

🔔 Alarm Otomatis

Alarm berbunyi tepat waktu sesuai jadwal harian.

🖥️ Background Mode

Tutup window, alarm tetap aktif lewat system tray.

🔕 Silent Mode

Notifikasi tanpa suara, cocok saat fokus.

📁 Audio Custom

Gunakan file WAV milik sendiri.

🌙 Mode Libur

Matikan alarm otomatis di hari tertentu.

⚡ Hemat CPU

Loop pintar, tidak membebani sistem.
